1 · Connect only your account

Microsoft consent requests Calendars.ReadBasic, the least-privileged calendar-list scope. This provider permission also permits basic event reading, but this application never calls event endpoints. Selecting a calendar does not narrow the Microsoft permission itself.

Authentication and privacy details

MSAL handles authorization code + PKCE in a popup. Its standard OpenID scopes are openid, profile and offline_access. Tokens stay in the page's memory, never local storage, session storage or application cookies. MSAL may use session storage for temporary request metadata, not tokens. No silent token acquisition or refresh is called.

Calendar IDs, names and owner metadata are processed only in this browser. No backend, assistant, other parent or family receives them. Other owners' calendar labels are discarded before rendering. This page cannot send invitations or emails.

Disconnect removes local access and cancels pending work. It does not sign out of Microsoft or revoke provider consent. To remove consent, use your organization's My Apps portal or contact its administrator. No tenant restrictions are bypassed.
